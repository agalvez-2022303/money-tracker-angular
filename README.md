# Money Tracker - Control de Finanzas Personales

Money Tracker es una aplicación web intuitiva diseñada para ayudarte a llevar el control de tus finanzas personales: cuánto entra, cuánto sale, en qué cuentas está tu dinero y qué tan cerca estás de tus metas (ahorro, inversión y gastos futuros).

## Características principales de la propuesta
- **Simple desde el primer clic:** Interfaz amigable diseñada para todo público, evitando tecnicismos y complejidades contables.
- **Registro rápido:** Agrega ingresos o gastos en menos de 10 segundos.
- **Visibilidad clara:** Filtros intuitivos para distinguir rápidamente entre gastos fijos y variables.
- **Metas personalizables:** Ajuste y seguimiento de tus propios objetivos financieros.

---
Este proyecto contiene el frontend recreado en **Angular** con animaciones fluidas y un diseño visual de alta calidad basado en el sistema de diseño de Aether Wealth.
